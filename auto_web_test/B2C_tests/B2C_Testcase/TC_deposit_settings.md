# 예약금 설정 테스트케이스

> **메뉴 경로**: 우리샵 관리 > 예약금 설정
> **URL**: /deposit/setting

---

## TC-01. 예약금 설정 페이지 진입

| 항목 | 내용 |
|------|------|
| **시나리오** | 사이드바에서 예약금 설정 페이지에 정상 진입하는지 확인 |
| **사전 조건** | 로그인 상태 |
| **절차** | 1. 사이드바에서 [우리샵 관리] 클릭<br>2. [예약금 설정] 클릭 |
| **확인 항목** | 1. "예약금 설정" 페이지 제목이 표시된다<br>2. 상단에 예약금 관련 안내 문구 4개가 표시된다<br>3. "공비서로 예약금 받기" 섹션이 표시된다<br>4. "예약금 금액 설정" 섹션이 표시된다<br>5. "예약 취소 환불 기준 설정" 섹션이 표시된다<br>6. "결제 대기 시간" 섹션이 표시된다<br>7. "회원권 고객 관리" 섹션이 표시된다<br>8. 우측에 "알림톡 미리보기(무료)" 영역이 표시된다 |

## TC-02. 안내 문구 확인

| 항목 | 내용 |
|------|------|
| **시나리오** | 페이지 상단의 예약금 관련 안내 문구를 확인 |
| **사전 조건** | 예약금 설정 페이지 진입 |
| **절차** | 1. 페이지 상단의 안내 문구를 확인한다 |
| **확인 항목** | 1. "예약금 받기 기능은 ①예약금 설정과 ②정산 정보 등록을 완료한 후 사용하실 수 있습니다." 문구가 표시된다<br>2. "정산 정보는 등록 후 3~5영업일 이내에 승인 또는 반려 처리되며, 승인 시 예약금 기능이 자동으로 활성화됩니다." 문구가 표시된다<br>3. "고객이 결제한 예약금은 [우리샵 관리 > 예약금 내역/정산] 메뉴에서 확인하실 수 있습니다." 문구와 링크가 표시된다<br>4. "예약금이 적용된 예약은 대기 상태로 등록되며, 결제 여부에 따라 예약 확정, 예약 취소 상태로 자동 변경됩니다." 문구가 표시된다 |

## TC-12. 토글 off 상태에서 저장 버튼 비활성화

| 항목 | 내용 |
|------|------|
| **시나리오** | "공비서로 예약금 받기" 토글이 off인 상태에서는 저장 버튼이 비활성화인지 확인 |
| **사전 조건** | 예약금 설정 페이지 진입, 토글 off 상태 |
| **절차** | 1. "공비서로 예약금 받기" 토글이 off인 상태에서 "저장" 버튼을 확인한다<br>2. 예약금 금액이나 드롭다운 등 설정값을 변경한다<br>3. "저장" 버튼 상태를 다시 확인한다 |
| **확인 항목** | 1. 토글 off 상태에서는 설정값을 변경하더라도 "저장" 버튼이 비활성화(disabled) 상태로 유지된다 |

## TC-13. 토글 on 전환 시 저장 버튼 활성화 및 저장

| 항목 | 내용 |
|------|------|
| **시나리오** | "공비서로 예약금 받기" 토글을 on으로 전환하면 저장 버튼이 활성화되고 저장이 가능한지 확인 |
| **사전 조건** | 예약금 설정 페이지 진입, 토글 off 상태 |
| **절차** | 1. "공비서로 예약금 받기" 토글을 on으로 전환한다<br>2. "저장" 버튼이 활성화되는지 확인한다<br>3. "저장" 버튼을 클릭한다 |
| **확인 항목** | 1. 토글 on 전환 시 "저장" 버튼이 활성화 상태로 변경된다<br>2. 저장 클릭 시 "예약금을 정산 받을 계좌 정보가 필요합니다." 팝업이 표시된다<br>3. 팝업에 "예약금 설정이 저장되었습니다." 메시지가 표시된다<br>4. 팝업에 [닫기], [정산 정보 등록] 버튼이 표시된다 |

## TC-14. 정산 정보 등록 모달 진입

| 항목 | 내용 |
|------|------|
| **시나리오** | 저장 후 나타나는 팝업에서 "정산 정보 등록" 버튼 클릭 시 정산 정보 등록 모달이 표시되는지 확인 |
| **사전 조건** | 예약금 설정 저장 후 정산 정보 안내 팝업 표시 상태 |
| **절차** | 1. 팝업의 [정산 정보 등록] 버튼을 클릭한다 |
| **확인 항목** | 1. "정산 정보 등록" 모달이 표시된다<br>2. 상단에 주의 사항 안내가 표시된다 (사업자등록증 정보 일치, 3~5일 확인, 수정 불가 안내)<br>3. "정산 정보" 섹션에 사업자등록증 업로드, 상호, 대표자, 사업자 등록번호 입력란이 표시된다<br>4. "계좌 정보" 섹션에 은행 드롭다운, 계좌번호 입력란, 계좌 확인 버튼이 표시된다<br>5. "전자 세금계산서 정보" 섹션에 이메일 입력란과 도메인 선택 드롭다운이 표시된다<br>6. 하단에 "저장" 버튼이 비활성화 상태로 표시된다 |
