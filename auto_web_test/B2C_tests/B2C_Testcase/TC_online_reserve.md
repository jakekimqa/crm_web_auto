# 공비서로 예약받기 테스트 케이스

> **URL**: https://crm-dev1.gongbiz.kr/b2c/setting?fromMenu=true
> **메뉴 위치**: 사이드바 > 온라인 예약 > 공비서로 예약받기

---

## TC-01. 공비서로 예약받기 페이지 진입

**시나리오**
사이드바에서 공비서로 예약받기 메뉴를 클릭하여 페이지에 진입한다

**사전 조건**
원장 계정으로 로그인 상태

**절차**
1. 사이드바의 "온라인 예약" 메뉴 클릭하여 하위 메뉴 펼침
2. "공비서로 예약받기" 클릭

**확인 항목**
1. 공비서로 예약받기 페이지(/b2c/setting)로 이동한다
2. 사이드바의 "공비서로 예약받기" 메뉴가 활성화(하이라이트) 상태이다

---

## TC-02. 상단 배너 영역 확인

**시나리오**
페이지 상단의 공비서 입점 안내 배너를 확인한다

**사전 조건**
공비서로 예약받기 페이지 진입 상태

**절차**
1. 상단 배너 영역을 확인한다

**확인 항목**
1. "공비서에 입점하면, 모든 카카오 알림톡 무료!" 안내가 표시된다
2. "내 샵 근처 1km 고객 이제 매장 단골로 만들어요" 제목이 표시된다
3. "고객이 먼저 찾아오는 샵 만들기, 공비서 입점에서 시작돼요" 설명이 표시된다
4. "20만 명 고객에게 자동으로 홍보되고, 예약으로 이어져요" 설명이 표시된다
5. "공비서 둘러보기" 버튼이 표시된다
6. "공비서 입점하기" 버튼이 표시된다

## TC-07. 공비서 입점하기 버튼 클릭

**시나리오**
공비서 입점하기 버튼을 클릭하여 온라인 예약 정보 등록 페이지에 진입한다

**사전 조건**
공비서로 예약받기 페이지 진입 상태

**절차**
1. "공비서 입점하기" 버튼 클릭

**확인 항목**
1. 온라인 예약 정보 등록 페이지(/b2c/setting/register)로 이동한다
2. "온라인 예약 정보" 제목이 표시된다
3. 상단에 "저장" 버튼이 비활성화 상태로 표시된다
4. "나가기" 버튼이 표시된다
